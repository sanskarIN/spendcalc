For reproducible software bugs, prefer a GitHub issue using the bug report template so fixes and workarounds remain searchable.

For security vulnerabilities, use the private contact process in [`SECURITY.md`](SECURITY.md) rather than a public issue.

## Before requesting help

Please include:

- SpendCalc version or commit SHA;
- Android version and device/emulator model;
- relevant setup/build command;
- expected and actual behavior;
- minimal reproduction steps;
- sanitized logs when relevant.

Do not send API keys, passwords, signing credentials, payment information, or private personal data.
