# Screenshots

This directory is reserved for verified release screenshots captured from the real Android build.

Do not present design mockups as production screenshots. Before the first tagged release, capture at least:

- calculator with itemized bill and receipt result;
- history screen;
- templates screen;
- settings in light and dark theme;
- About screen with project credit/support links;
- a tablet/wide layout.

Capture screenshots only with fictional/demo expense data and no personal notifications or device information.
